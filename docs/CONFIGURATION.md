# 配置

**简体中文** · [English](CONFIGURATION.en.md)

| 功能 | 设置 |
| --- | --- |
| 语言 | 跟随系统、中文或英文 |
| 额度刷新 | 手动、1/5/15 分钟；刷新失败时保留上次读数和采集时间 |
| Codex 来源 | 选择本机读取程序；安装位置或程序身份变化时重新确认 |
| 账号 | 添加、续期和查看账号；切换当前登录时确认操作 |
| 工作日程 | 设置工作和停用时段，按当前额度分配日程预算 |
| 规划实验室 | 默认关闭；开启后查看近期用量推算和核验记录 |
| 历史 | 按账号保存；首次访问时按需完成系统授权 |
| Provider/API | 配置服务地址、模型和凭据，预览后应用变更 |
| CPA 额度池 | 默认关闭；设置 SSH 目标与查询命令后启用 |
| 重置雷达 | 后台每 15 分钟采集公开来源，支持手动刷新 |

账号和历史保存在本机。查看多个账号的额度时可保留当前登录。
CPA 的环境变量和返回格式见 [CPA bridge](CPA_BRIDGE.md)，历史授权见[安装指南](INSTALLATION.md#历史授权)。

## 重置雷达

概览并列展示未来 24 / 48 小时的判断。有效的明确预告覆盖对应窗口时优先按 100% 判定，
同时保留模型估计、预告时间与后续完成情况。

macOS 安装包自带[独立预测与评估模块](DEVELOPMENT.md#接入桌面雷达)，打开应用即开始后台采集，无需另装 Python。
主判断采用“重置或发放新重置卡”的概率，
自动重置概率作为并列参照。未来 72 小时曲线显示综合、社区与历史基准；来源对照保留各雷达
发布时的原值、事件范围与时间。展开模型输入可查看转换后的 24h / 48h 值和来源支持的期限。
未通过质量或口径审查的来源留在明细中。过期结果显示更新时间并保留上次值。

社区面板显示合并概率、实际组权重，以及完整模型与移除社区对照模型之间的百分点差。
“社区原始投票”保留 Codex Reset 的日期分布和 NextReset 的每日概率投票、原期限及票数。
历史走势图同时呈现 Horizon 与各来源，实线为 24h、虚线为 48h；从评估器实际收到预测时起，
按统一时钟记录，缺失窗口留空。悬停可查看时间和概率。

“本次判断为何变化”比较同一模型版本实际发布的预测，并列显示 24h / 48h 的变化和各来源、
社区及事件包含关系调整的贡献。展开可查看输入、权重和来源原值的前后对照；新版本先积累对照。

“预测经得起检验吗”显示冻结记录、结算进度、实际重置与发卡证据。窗口成熟且事件观测覆盖充分后，
自动显示 Brier 分数、对数损失、校准图、预警质量和同窗对照；两个损失分数越低越好。
首次运行会先显示积累进度。事件证据更正后，评估器会更新结算。
展开评分计数可按 6h / 12h / 24h / 48h 查看已结算窗口、主评分和滚动核验；
多家来源在同一窗口分别记分，评分条数与实际重置次数分别显示。
已到期但证据有缺口或分歧的窗口会显示待补足证据。Horizon 运行时
定期检查独立进程，退出的进程会重新启动；电脑重启后打开 Horizon 即可恢复采集。

尚未连接独立模块的安装继续使用内置雷达：汇集 Codex Reset、Reset Monitor、NextReset、
公开社区讨论和投票，保留来源状态与采样明细。
Tibo 的重点发言默认完整显示，中文界面同时呈现英文原文和已有译文。“其他动态与回复”包含
重置无关的内容，可筛选回复、展开全文和已取得的上文，也可前往 X 查看更多互动。
每日“发布改进或完整重置”这类条件承诺会在有效期间持续展示，完整保留条件与持续时间。

“重置历史”用近三个月的日历区分额度重置、重置卡发放和预告。点击日期可查看按电脑时区换算的事件时间。
新内容以小点提示，阅读后自动标记，也可点击“全部已读”。来源名称与更新时间随内容显示；连接失败时保留上次结果。
