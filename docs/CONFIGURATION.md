# 配置

**简体中文** · [English](CONFIGURATION.en.md)

| 功能 | 设置 |
| --- | --- |
| 语言 | 跟随系统、中文或英文 |
| 额度刷新 | 手动、1/5/15 分钟；刷新失败时保留上次读数和采集时间 |
| Codex 来源 | 选择本机读取程序；安装位置或程序身份变化时重新确认 |
| 账号 | 添加、续期和查看账号；切换当前登录时确认操作 |
| 工作日程 | 设置工作和停用时段，按当前额度分配日程预算 |
| 规划实验室 | 默认关闭；开启后查看近期用量推算和核验记录 |
| 历史 | 按账号保存；首次访问时按需完成系统授权 |
| Provider/API | 配置服务地址、模型和凭据，预览后应用变更 |
| CPA 额度池 | 默认关闭；设置 SSH 目标与查询命令后启用 |
| 重置雷达 | 后台每 15 分钟采集公开来源，支持手动刷新 |

账号和历史保存在本机。查看多个账号的额度时可保留当前登录。
CPA 的环境变量和返回格式见 [CPA bridge](CPA_BRIDGE.md)，历史授权见[安装指南](INSTALLATION.md#历史授权)。

## 重置雷达

概览并列展示未来 24 / 48 小时的 Horizon 试验性综合估计、来源原值和社区贡献。
有效的明确预告覆盖对应窗口时优先按 100% 判定，预告时间、适用范围和后续完成情况在动态区追踪。
[Codex Reset](https://codex-reset.com/) 和 [Codex Reset Monitor](https://codexreset.org/) 的预测保留原值；
展开“依据与来源审查”可检查权重、共用原帖、更新时间和未纳入来源的原因。过期或采集失败的已审查来源保留显示并退出综合计算。

同一张走势图用颜色区分 Horizon 与各来源，实线表示 24h、虚线表示 48h。Horizon 和来源观测值从本机记录时刻累积，同时保留 Monitor 提供的历史；悬停数据点可看时间与概率。
社区面板展示过去 24 小时的 GitHub 与 Hacker News 公开采样，包括活跃重置话题的回复，分别统计预测、愿望和情况反馈。
有效期内的明确预测按作者、重复内容、共享依据和时效折算贡献，两个窗口分别显示有效样本与调整点数；“查看观点、依据与采样范围”列出原文和采集状态。
微信、Reddit 与 Linux.do 尚未接入。暂缺方向明确的预测时显示 `—`。
Tibo 的重点发言默认完整显示，中文界面同时呈现英文原文和已有译文。旁边的“其他动态与回复”包含重置无关的内容，可筛选回复、展开全文和已取得的父帖，也可前往 X 查看更多互动。
“综合估计如何计算”说明当前试验权重与社区调整规则。
事件历史汇集 Codex Reset 与 [QuotaResets](https://quotaresets.com/) 的记录，服务状态来自 [OpenAI Status](https://status.openai.com/)。

“重置历史”用近三个月的日历区分额度重置、重置卡发放和预告。点击日期可查看按电脑时区换算的事件时间。
新内容以小点提示，阅读后自动标记，也可点击“全部已读”。来源名称与更新时间随内容显示；连接失败时保留上次结果。
